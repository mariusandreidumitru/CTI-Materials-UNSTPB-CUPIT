PARSAREA FISIERELOR XML

XML - are tag-uri ca si HTML. Diferente:
-tagurile HTML sunt predefinite. Tagurile XML noi le creem, le denumim
-tagurile HTML descriu modul in care browserul va afisa informatia.
 Tagurile XML descriu structura documentului

Un exemplu de fisier XML care contine numere complexe:
<NUMERE_COMPLEXE>
  <complex>
     <re>5</re>
     <im>7</im>
  </complex>
  <complex>
     <re>-5</re>
     <im>-7</im>
  </complex>
  <complex>
     <re>15</re>
     <im>17</im>
  </complex>
</NUMERE_COMPLEXE>


Fisierul XML cu carti:
<CARTI>
 <carte>
   <autor>Ion Creanga</autor>
   <titlu>Amintiri din copilarie</titlu>
   <nr_exemplare>7</nr_exemplare>
 </carte>
 <carte>
   <autor>Ion Slavici</autor>
   <titlu>Mara</titlu>
   <nr_exemplare>3</nr_exemplare>
 </carte>
</CARTI>

Prelucrarea unui fisier XML se cheama parsere.
Vom folosi parserul StaX.
Ideea de parsare:
Se creeaza un obiect reader si cu acest obiect reader parcurgem fisierul, cu metoda next() ce returneaza un numar intreg, numar ce corespunde unui eveniment. Ex. de evenimente:
-inceput de tag
  Ex: intalneste tagul <complex> sau tagul <re>
-sfarsit de tag
  Ex: </complex> sau </re>
-caractere (text)
  Ex: -5 
  Ex: "Ion Creanga"

<NUMERE_COMPLEXE>
    <complex>
        <re>2.5</re>
        <im>1.5</im>
    </complex>
    <complex>
        <re>-3.0</re>
        <im>4.0</im>
    </complex>
    <complex>
        <re>1.0</re>
        <im>-2.5</im>
    </complex>
    
</NUMERE_COMPLEXE>


public class Complex {
    private double re;
    private double im;

    public Complex() {
    }
    public Complex(double re, double im) {
        this.re = re;
        this.im = im;
    }

    public double getRe() { return re; }
    public void setRe(double re) { this.re = re; }

    public double getIm() { return im; }
    public void setIm(double im) { this.im = im; }

    public Complex add(Complex c) {
        return new Complex(this.re + c.re, this.im + c.im);
    }

   
}

import java.util.*;
import java.io.*;
import javax.xml.stream.XMLInputFactory;
import javax.xml.stream.XMLStreamConstants;
import javax.xml.stream.XMLStreamException;
import javax.xml.stream.XMLStreamReader;

public class Main
{
 public static void main(String args[]) throws FileNotFoundException, XMLStreamException
 //am folosit clauza throws, pt a nu mai trata aceste exceptii in blocuri try...catch
 {
  ArrayList<Complex> al=null;
  Complex pCrt=null;  String continutTag=null;
  File file = new File("numere.xml");
  XMLInputFactory factory = XMLInputFactory.newInstance();
  XMLStreamReader reader = factory.createXMLStreamReader(new FileReader(file));

  while(reader.hasNext()){//cat timp nu s-a terminat fisierul xml
  	//citim ce eveniment a fost intalnit de reader:
	int event=reader.next();//Acesta este API-ul de tip „cursor” (iterator pe evenimente).

//reader.next() avansează cursorul la următorul eveniment din fluxul XML.

//După apel, poți afla ce tip de eveniment este (start element, text, end element etc.) folosind metode
	if(event==XMLStreamConstants.START_ELEMENT){//inceput de tag (de element)
	  String s=reader.getLocalName();//getLocalName citeste numele tag-ului xml
 	  if(s.equals("NUMERE_COMPLEXE"))//daca este tagul NUMERE_COMPLEXE
	    al=new ArrayList<Complex>();
	  else if(s.equals("complex")) //daca este tagul complex
		pCrt=new Complex();
	}else if(event==XMLStreamConstants.CHARACTERS)
	  continutTag=reader.getText().trim();//citeste informatia dintre <tag> si </tag>
	  //trim (): scoate spatiile de la inceput sir si de la sfarsit sir
	else if(event==XMLStreamConstants.END_ELEMENT){//s-a terminat un tag
	  String s=reader.getLocalName();	//vedem ce tag a fost
	  if(s.equals("re"))pCrt.setRe(Double.parseDouble(continutTag));
	  else if(s.equals("im"))pCrt.setIm(Double.parseDouble(continutTag));
          else if(s.equals("complex"))al.add(pCrt);
	}//if END_ELEMENT
  }//end while reader.hasNext()
  //Suma:
  Complex suma=new Complex(0,0); 
  for(int i=0;i<al.size();i++) {
  	suma.setRe(suma.getRe()+al.get(i).getRe());
	suma.setIm(suma.getIm()+al.get(i).getIm());
  }
  System.out.println(suma.getRe()+" + "+suma.getIm()+"i");

 }
